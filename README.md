# AI Concierge - Supply Chain Bridge

The intelligent glue that connects the **AI Concierge (Copilot)** with the **AI Supply Chain Optimizer**.

## 🚀 Overview
Normally, an AI assistant can talk about your ERP data. But with this bridge, the assistant gains "Supply Chain Awareness". It can interpret complex forecasting models, explain replenishment suggestions, and help you take inventory decisions in natural language.

## ✨ Key Features
- **Intelligent Querying**: Ask Gemini about inventory exceptions and forecast rationale.
- **Contextual Awareness**: The AI Concierge automatically knows when a product is overstocked based on Supply Forecast data.
- **Unified Interface**: Integrated OWL components that show supply insights directly in the chat sidebar.

## 📦 Installation
1. Ensure both `ai_concierge` and `supply_forecast` are installed.
2. Search for "AI Concierge - Supply Chain Bridge" in the Odoo Apps menu.
3. Click **Activate**. (Note: This module is set to `auto_install=True` if dependencies are met).
